# 仓库维护文档

`docs/` 只服务于 **MUM Workflows 本仓库的维护者**，当前仅记录后续改进建议；不承担新手教程、比赛操作、参考资料或练习任务。

- 想查资料：去 `preference/`。
- 想学习：去 `tutorials/`。
- 想动手练：去 `practice/`。
- 想在真实比赛中执行：去 `workflows/` 和 `templates/`。
- 想维护或提议改进本仓库：阅读本目录、根 `CONTRIBUTING.md` 与 `AGENTS.md`。

当前待办与取舍见 [后续改进建议](maintenance/future-improvements.md)。
