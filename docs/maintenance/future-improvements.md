# 后续改进建议

本文件记录已识别但暂不进入当前轻量版本的方向。维护者应优先挑选范围小、可验证且不依赖受限资料的条目。

## 高价值、下一步可做

1. 为 `mini-modeling-sprint/` 补一份虚拟 CSV、baseline 脚本和预期产物，使新人不必先自行找数据。
2. 为教程补充最小命令、预期输出和常见错误处理，优先 Git、项目初始化与 Python 图表三章。
3. 在 `preference/methods/` 增加少量方法卡：适用场景、最小 baseline、验证方式、常见误用和局限。
4. 为四个 `MCM-` Skill 补充实际使用示例；仅在有稳定需求后再新增 Skill。

## 需要更多维护能力后再做

- CUMCM、MCM/ICM、电工杯各自的论文骨架和规则核对模板；每年必须重新确认官方要求。
- 赛事专属完整 Skill、算法大目录和 AI 长提示词集；这些内容会快速过期或需要更严格的来源维护。
- 自动检查 Markdown 链接、缓存文件和大文件的轻量 CI。
- 带基线对比的复杂 Skill 评测框架；当前只做 frontmatter、链接和目录结构检查。
- Origin 的项目文件示例、更多 Python 图表类型与无障碍配色指南。
- 术语表、参考资料登记表和变更日志。

## 不应纳入本仓库

- 进行中的赛题、原始附件、未公开结果或个人信息；
- 未授权的算法代码、论文和课程资料；
- 承诺获奖、自动判定模型正确或代替官方规则的内容。
