# 练习区

练习区使用公开、虚拟或去标识化材料，目标是练习协作闭环，而不是复刻真实比赛答案。

| 练习 | 用时 | 目标 |
| --- | --- | --- |
| `git-collaboration/` | 30–60 分钟 | 分支、PR、冲突和交接 |
| `visualization/` | 30–90 分钟 | AI 示意图、Python 图表或 Origin 软件作图 |
| `mini-modeling-sprint/` | 2–4 小时 | 任务卡、baseline、结果追溯 |
| `paper-assembly/` | 60–90 分钟 | 将已验证结果装配为论文片段 |
