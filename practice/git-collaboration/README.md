# Git 协作练习

这是独立的 Git 协作练习。提交物可以是图表、流程示意、文档或小型代码改动；图表制作方式另见 [可视化练习](../visualization/README.md)。目标是练习团队协作，而不是展示图片本身。

## 练习步骤

1. 在自己的 fork 或练习仓库中创建 `feat/practice-<github-id>` 分支。
2. 任选一个小交付物：可视化练习产物、`image-prompts/` 中的示意图，或一份短文档。
3. 将用途、文件名和自检记录写入提交说明；使用规范提交信息。
4. 发起 PR，请另一位练习者按 PR 模板审核；合并后完成一次交接说明。

## 验收

- [ ] 分支、提交与 PR 的目的清晰。
- [ ] 图片文件和文档链接可访问，且不含个人/赛题敏感信息。
- [ ] 至少由另一人完成一次审核或冲突演练。
- [ ] 能说明下一位队员如何找到任务、修改记录与最终成果。

辅助资料：[提交信息规范](commit-convention.md)、[Git 常用指令](git-quick-reference.md)、[示意图任务](image-prompts/README.md)、[可视化练习](../visualization/README.md)。
