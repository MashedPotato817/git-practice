# 生图任务清单

从下列任务中任选一个，使用 AI、生图软件、PPT/绘图软件或手工绘制完成一张**结构示意图**，再将它作为 Git 协作练习的提交物。整体流程见[根 README](../../../README.md)。

## 任务列表（建议按顺序）

| 任务 | 图型 | 应用场景 |
|------|------|----------|
| [任务 1：系统框图](系统框图.md) | 系统架构框图 | 数模论文中的模型总体结构 |
| [任务 2：算法流程图](算法流程图.md) | 算法流程图 | 数模论文中的求解算法描述 |
| [任务 3：结果分析图](结果分析图.md) | 灵敏度分析折线图 | 数模论文中的结果分析章节 |

## 使用方法

1. 打开任务文件，选择适合的制作方式；其中「提示词正文」仅是 AI 生图可选方案
2. 按任务说明制作图片
3. 对照「验收要点」检查；涉及流程或数据关系时必须由人工核对准确性

## 重要约定

- **练习者 id**：统一使用你的 GitHub 用户名
- **图片命名**：`<提示词名>-<练习者id>.png`，如 `系统框图-zhangsan.png`
- **格式与大小**：PNG、JPG、SVG 或 PDF；单文件建议 < 1MB
- **存放位置**：`../images/`
- **工作分支**：`feat/practice-<练习者id>`，如 `feat/practice-zhangsan`
- **commit 示例**：`feat(practice): 添加系统框图-zhangsan`（规范详见 [提交信息规范](../commit-convention.md)）
- **PR 标题**：与 commit 格式一致，如 `feat(images): 添加系统框图-zhangsan`
- **禁止直接 push main**，一切通过 PR 合并

AI 生成的图片不应用于伪造实验数据、数值曲线或结论。数值图表请使用 Python 或 Origin 等软件，并保留数据来源与作图参数。完成后在 PR 中说明图片用途、制作方式、文件路径与验收结果；不再维护根 README 的成果展示表。
