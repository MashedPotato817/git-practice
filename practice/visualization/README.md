# 可视化练习

数模图表分为两类：解释模型结构的**示意图**，以及由数据和计算结果支撑的**数值图表**。两类不能混用。

| 路径 | 适用产物 | 练习入口 |
| --- | --- | --- |
| AI / 手工示意图 | 系统框图、算法流程、概念关系 | `../git-collaboration/image-prompts/` |
| Python | 可复现的折线、柱状、散点、热力等数值图 | `python-charts/` |
| Origin | 交互式科研作图与版式调整 | `origin-charts/` |

## 共通验收

- [ ] 图的标题、坐标轴、单位、图例和数据范围清楚。
- [ ] 数值图能追溯到数据、处理步骤和作图参数。
- [ ] 图表只陈述数据支持的结论，不把模拟或示意写成真实事实。
- [ ] 导出文件能嵌入论文，保留原始数据和可编辑源文件。
