# Origin 软件作图练习

Origin 适合需要交互式调整版式、误差线、分面和论文级导出的场景。它不能替代数据清洗或统计判断。

## 练习步骤

1. 导入 `../python-charts/waiting_time.csv`；确认第一列是 X，后两列是 Y，单位为分钟。
2. 绘制双折线图，添加标题、轴名称、单位和图例。
3. 调整线型、标记、坐标范围和留白，使两组方案可区分但不过度装饰。
4. 将 Origin 工程文件、导出 PDF/PNG 与数据来源说明保存在同一项目目录。
5. 在实验记录中写下导入范围、作图类型、关键格式设置与导出时间。

## 导出建议

- 优先 PDF、SVG、EMF 等矢量格式；位图至少 300 dpi。
- 论文中的图号和标题由论文源统一控制，不把大段解释文字烘焙进图片。
- 如果数据或结论更新，回到源数据与工程文件重画；不要只修导出的图片。
