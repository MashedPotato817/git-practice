# 论文装配练习

用时 60–90 分钟。本练习使用虚拟结果，只训练表达、引用和一致性检查。

## 虚拟结果

- 基线方案的平均等待时间为 18.4 分钟。
- 改进方案的平均等待时间为 14.7 分钟。
- 在需求增加 20% 的情景下，改进方案为 17.3 分钟。
- 结果来自模拟数据，不能推广为真实校园的事实结论。

## 任务

1. 在 Markdown 中写一段“结果分析与检验”，包含比较、敏感性分析和局限。
2. 用 `templates/project-starter/Paper/main.tex` 的章节骨架写一个对应 LaTeX 段落。
3. 检查两份文本的全部数字和限定语是否一致。

## 验收

- [ ] 不把模拟结果写成现实调查结论。
- [ ] 每个数字有明确对象、单位或情景。
- [ ] 包含至少一项局限或不确定性。
- [ ] Markdown 和 LaTeX 的结论口径一致。
