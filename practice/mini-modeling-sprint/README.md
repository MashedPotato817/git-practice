# 小型建模冲刺练习

用时 2–4 小时。请自行选择一个公开、可分享的小数据集，或使用人工构造数据；不得放入真实比赛题面或受限附件。

## 任务

以“校园共享单车需求预测与投放建议”为虚拟背景，完成一个最小闭环：

1. 写一张任务卡：输入、输出、假设、负责人、验收条件。
2. 做一个透明 baseline，例如按历史均值预测或按区域需求排序投放。
3. 生成至少一张带标题、坐标轴和单位的图表。
4. 记录一个局限，以及一个可执行的改进实验。
5. 写 200–300 字 Markdown 结果说明，不夸大结论。

## 验收

- [ ] 别人能找到数据来源和运行命令。
- [ ] 结果、图表和文字叙述使用同一批输出。
- [ ] 明确区分数据支持的结论与尚未验证的推测。
- [ ] 在决策日志中留下至少一次模型选择理由。
