# 资料库

这里保存可公开、可维护的“索引与方法说明”，而不是把大量来源不明的代码或随年份失效的竞赛规则直接堆进仓库。

| 分类 | 用途 | 维护原则 |
| --- | --- | --- |
| `competitions/` | 各赛事规则核对入口与差异 | 必须标注核对日期；以官网为准 |
| `methods/` | 题型与模型方法的选择索引 | 给适用条件、数据要求、局限和验证办法 |
| `tools/` | Python、LaTeX、Git 等工具入口 | 只记录最小可用操作与可靠来源 |
| `references/` | 外部材料索引 | 记录来源、许可证与可否复制 |

所有资料应帮助队伍作出可验证的选择，不能替代真实数据、题意理解或官方要求。
