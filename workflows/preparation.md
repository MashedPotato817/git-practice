# 赛前准备工作流

目标是在开赛前暴露“能否协作、能否复现、能否交付”的问题。

## T-14 至 T-7 天

1. 从 `templates/project-starter/` 复制项目骨架，创建私有演练仓库。
2. 三人分别完成一次分支、PR、冲突解决与交接记录演练。
3. 检查 Python、Git 与 LaTeX（XeLaTeX 或 pdfLaTeX）是否可用，将真实命令写入项目 README。
4. 用公开小案例跑通“任务卡 → 脚本 → 图表 → 论文引用”。

## T-7 至 T-1 天

1. 整理公开算法索引、文献检索策略和绘图规范，不预设本届答案。
2. 预填论文骨架的章节标题、图表目录和引用约定，实际内容保持为空。
3. 建立当届官方规则入口清单；开赛后仍必须重新核对。
4. 明确成员可用时间、电脑环境、联系人和最终提交责任人。

## 开赛前 30 分钟

- [ ] 私有仓库、成员权限和分支规则已验证。
- [ ] 任务卡、决策日志和论文骨架的位置明确。
- [ ] 每人能运行最小 Python 示例，至少一人能编译 LaTeX 骨架。
- [ ] 已约定每 2–4 小时短同步，以及冲突/阻塞时找谁决策。
