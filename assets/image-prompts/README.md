# 生图任务清单

从下列任务中任选一个，复制提示词正文到任意 AI 生图模型（如 GPT-Image2）生成图片，完成一次完整的 git 协作练习。整体流程见[根 README](../../README.md)。

## 任务列表（建议按顺序）

| 任务 | 图型 | 应用场景 |
|------|------|----------|
| [任务 1：系统框图](系统框图.md) | 系统架构框图 | 数模论文中的模型总体结构 |
| [任务 2：算法流程图](算法流程图.md) | 算法流程图 | 数模论文中的求解算法描述 |
| [任务 3：结果分析图](结果分析图.md) | 灵敏度分析折线图 | 数模论文中的结果分析章节 |

## 使用方法

1. 打开任务文件，复制「提示词正文」整段
2. 粘贴到生图模型生成图片
3. 对照「验收要点」检查，不合格就修改提示词重试

## 重要约定

- **图片命名**：`<提示词名>-<练习者id>.png`，如 `系统框图-zhangsan.png`
- **格式与大小**：PNG 或 JPG，单张 < 1MB
- **存放位置**：`assets/images/`
- **工作分支**：`feat/images-<练习者id>`，如 `feat/images-zhangsan`
- **commit 示例**：`feat(images): 添加系统框图-zhangsan`（规范详见 `.agents/skills/git-workflow/SKILL.md` 与 [preference/Git 提交信息规范](../../preference/Git%20提交信息规范.md)）
- **PR 标题**：与 commit 格式一致，如 `feat(images): 添加系统框图-zhangsan`
- **禁止直接 push main**，一切通过 PR 合并

完成后别忘了把成果加入根 README 的「成果一览」表。
