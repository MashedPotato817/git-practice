# 赛事规则核对入口

比赛规则、论文格式、匿名要求、AI 使用政策和提交方式每年都可能调整。本目录只保存核对方法，不保存“永久正确”的结论。

开赛与提交前至少记录：赛事与年份、官方链接、文件发布日期、最后核对人、与团队工作流有关的限制。

| 赛事 | 开赛前应核对 | 提交前应再次核对 |
| --- | --- | --- |
| CUMCM | 赛题获取、论文格式、AI 使用与队内资料边界 | 匿名、格式、支撑材料与提交系统 |
| MCM/ICM | COMAP 当届 Instructions、报告与工具要求 | 页数、文件名、队伍控制号与提交方式 |
| 电工杯 | 官网当届通知、论文规范与材料要求 | 匿名、格式、附件与截止时间 |
