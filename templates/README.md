# 模板库

`project-starter/` 是可复制到新私有仓库的最小骨架。它提供目录边界、任务卡、决策日志、Python 入口与 LaTeX/Markdown 论文骨架；不提供任何特定赛题的实现或保证当届格式合规。

不需要完整骨架时，可单独复制以下高频模板：

- [任务卡](task-card.md)
- [决策日志](decision-log.md)
- [项目 README](project-readme.md)
- [Markdown 论文骨架](paper-outline.md)
- [提交前检查清单](pre-submit-checklist.md)

复制后第一件事是填写项目根 `README.md` 中的比赛、规则入口、截止时间和运行命令。
