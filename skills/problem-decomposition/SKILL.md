# 子问题拆解

1. 先摘录与当前子问题相关的准确题意，区分题目给定、团队假设和待查事实。
2. 为每个子问题写输入、输出、变量/约束、依赖、负责人、验收条件和风险。
3. 标出串行依赖与可并行工作；不要把“先做哪个模型”伪装成题目事实。
4. 将假设和模型选择理由写入决策日志；未验证项保持为待验证。

产物为 `demand/` 中的任务卡与一张依赖说明。需要队员确认题意理解和分工边界后才进入求解。
