# Skill 库

本目录的 Skill 是给 Agent 或人工协作者使用的“工作约定”，不是新人教程，也不是自动解题器。先完成相关教程或练习，再按需使用 Skill。

## 最小用法

1. 先阅读目标 Skill 的 `SKILL.md`，确认它适用的场景和人工确认点。
2. 使用 Agent 时，按该工具的官方 Skill 安装方式复制整个 Skill 文件夹；手动协作时，直接把其中步骤作为任务清单。
3. Skill 的输出仍需由队员核对数据、题意、结果和当届规则。

| Skill | 用途 |
| --- | --- |
| `contest-project-workflow` | 从开赛到交付的项目主线 |
| `problem-decomposition` | 将题面拆成可验收任务卡 |
| `reproducibility-check` | 检查结论的来源和复现入口 |
| `paper-consistency-review` | 检查论文与结果的口径一致性 |
