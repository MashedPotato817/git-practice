# 数学建模竞赛项目工作流

## 先确认

确认比赛与年份、截止时间、题面/数据位置、成员与可用时段、公开/私有边界、允许工具，以及当届官方规则入口。没有原始数据或准确题意时，不得编造结果。

## 步骤

1. 阅读项目 README、协作约定、任务卡、决策日志与 Git 状态。
2. 将题目拆成可验收子问题：输入、输出、假设、依赖、负责人、验收条件。
3. 先实现最小 baseline，再记录模型候选、采用理由和被放弃方案。
4. 关联代码、参数、种子、数据处理、结果和图表；关键结论提供复现命令与局限。
5. 结果变化时定位受影响的子问题、图表和论文段落，局部更新，不静默覆盖旧结论。
6. 提交前重新核对当届规则、匿名/格式、AI 使用要求和最终 PDF。

## 人工确认点

选题、核心假设、模型取舍、关键结果解释、AI 使用披露和最终提交均需队员确认。
