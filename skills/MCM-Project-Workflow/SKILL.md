# MCM 项目工作流

## 输入与产物

输入是题面、数据位置、团队约束和当届官方规则入口。产物是任务卡、决策记录、可复现代码、结果图表和可追溯的论文材料。

先确认比赛与年份、截止时间、成员与可用时段、公开/私有边界和允许工具。没有准确题意或原始数据时，记录未知项，不编造结果。

## 工作流程

1. 阅读 README、任务卡、决策日志和 Git 状态，确认当前事实与阻塞点。
2. 为每个子问题写任务卡：题意、输入、输出、假设、依赖、负责人和验收条件。
3. 检查数据字段、单位、范围、缺失和异常；将清洗规则写进代码或记录，不能只手工修改。
4. 先实现可解释的 baseline，再比较复杂方案；同一比较必须使用同一输入和指标。
5. 记录参数、随机种子、依赖、运行命令和输出位置；关键结论须能回溯到输入和脚本。
6. 验证约束、量纲、边界情形和敏感性；结果变化时同步受影响的图表和论文段落。

## 交接与人工确认

交接时留下当前状态、已验证内容、未验证风险、下一步、复现命令和相关文件。

选题、核心假设、模型取舍、关键结果解释、AI 使用披露和最终提交均需队员确认。此 Skill 不能替代题意理解、事实核验或当届规则。
