# MCM 图表制作

## 输入与产物

输入是图表目的、数据或模型输出、目标论文位置和可用工具。产物是带清楚标题、单位、图例和来源的图表，以及对应脚本、数据说明或软件工程文件。

## 先区分图表类型

- **示意图**：表达流程、结构或概念关系，可使用 Mermaid、绘图软件或 AI 辅助，但必须人工核对关系正确。
- **数值图**：表达数据、模型输出或实验比较，应由 Python、Origin 等可追溯流程制作，不能用 AI 生图伪造曲线或结论。

## 制作流程

1. 先写图要回答的问题，再选择图型；时间变化用折线，类别比较用柱状，变量关系用散点，空间/矩阵结构才考虑热力图。
2. 从同一份可追溯数据生成图；记录处理步骤、筛选条件、单位和作图参数。
3. 保留标题、坐标轴、单位、图例和必要的误差/情景说明；避免装饰压过数据。
4. Python 图保留脚本和依赖；Origin 图保留源数据、工程文件和导出设置；优先导出论文可用的矢量格式。
5. 嵌入论文前，核对图中数字、单位和图题是否与正文一致，并检查黑白打印和缩放后的可读性。

## 人工确认点

队员必须确认数据来源、比较对象、图型是否支持结论，以及图表没有夸大差异。无法追溯的图只能作为草图，不能作为正式证据。
